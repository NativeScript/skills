# Device APIs without plugins

Location, geocoding and time zones, haptics, sensors, camera, notifications — reached through the platform APIs directly so an app does not take on a plugin dependency for one feature. Each skill covers iOS and Android.

**Belongs here:** a device capability with both platform paths and the permission/plist/manifest setup.

**Doesn't:** skills about *writing* plugins (→ `plugins/`), single-platform API tours (→ `ios/`, `android/`).

**Naming:** `ns-<capability>`.
