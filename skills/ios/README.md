# iOS native from TypeScript

Driving UIKit, SceneKit, CoreLocation, Metal and other Apple frameworks directly from TypeScript: framework typings, exact selector spelling, delegate classes, render loops, sheets, Liquid Glass.

**Belongs here:** skills whose substance is an Apple API and how the NativeScript iOS runtime exposes it.

**Doesn't:** cross-platform device features with an iOS *and* Android path (→ `device/`), UI patterns that also ship an Android renderer (→ `ui/`).

**Naming:** `ns-ios-<topic>`.
